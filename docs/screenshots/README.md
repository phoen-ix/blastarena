# Screenshot gallery

Every screen of BlastArena, one sentence each. All images come from the docs tour
(`bash scripts/docs-screenshots.sh`, see the main [README](../../README.md#screenshots)) against a
seeded demo: fictional players, maps and matches, dated June 2026. Arena layouts in the open world and
in matches are generated by the server, so those few shots differ from run to run.

## Landing and sign-in

### Landing page
The first screen: the live open-world arena runs behind the title and the Play as Guest, Login and
Register buttons. The visitor is already in it as a guest, shown above the title until the first game
key moves the buttons out of the way.

<img src="menu-landing.png" alt="The landing page: BlastArena title and Play as Guest, Login and Register buttons over the live open-world arena, the guest character above the title" width="800">

The same page for a browser set to German (the language follows the browser on a first visit).

<img src="menu-landing.de.png" alt="The landing page in German: Als Gast spielen, Anmelden and Registrieren" width="800">

### Login
Username and password, with the language picker, the switch to registration and the forgot-password
link.

<img src="auth-login.png" alt="The login form with username and password fields" width="800">

<img src="auth-login-error.png" alt="The login form showing an invalid-credentials error" width="800">

### Register
A new account needs a username, an email address and a password; it can play once the email is
